## Изменённые файлы

- `UpdateQuantityAjax()` - изменение количества без перезагрузки
- `GetCartData()` - получение актуальных данных корзины

### Controllers/HomeController.cs
✅ **Упрощение**: Удалена демо-функция `GetPopularProducts()`

### Views/Product/Catalog.cshtml
✅ **Полная переработка**:

- Кнопки с AJAX функционалом
- Уведомления при добавлении товаров

### Views/Cart/Index.cshtml
✅ **Добавлена AJAX функциональность**:
- Удаление товаров без перезагрузки
- Изменение количества без перезагрузки

✅ **Динамический счетчик корзины**:

## Структура данных товаров

Каждый товар содержит:
```csharp
{
  Id: int,
  Name: string,
  Category: string,
  Price: decimal,
  Description: string,
  ImageUrl: string,
  Stock: int
}
```

## Структура данных корзины

Каждый товар в корзине содержит:
```csharp
{
  Id: int,
  ProductId: int,
  ProductName: string,
  Price: decimal,
  Quantity: int,
  ImageUrl: string,
  Total: decimal (Price * Quantity)
}
```

## Как добавить новый товар

В `ProductController.cs`, в методе `GetAllProducts()`:

```csharp
new() { 
  Id = 25, 
  Name = "Новый товар", 
  Category = "Ручки", 
  Price = 50, 
  Description = "Описание товара", 
  ImageUrl = "/images/product.jpg", 
  Stock = 100 
}
```

## Технические детали

### Дебаундинг поиска
Поиск с задержкой 300мс для оптимизации - не отправляет запрос на каждый символ, а ждёт когда пользователь остановится печатать.

### HTML-экранирование
Функция `escapeHtml()` защищает от XSS атак при выводе названий и описаний товаров.

### Сессия корзины
Корзина хранится в HttpContext.Session с ключом "cart" и сохраняется между запросами.

### AJAX операции
Все AJAX запросы используют Fetch API (встроен в современные браузеры):
- Content-Type автоматически устанавливается на application/x-www-form-urlencoded
- Ошибки ловятся и выводятся пользователю
- Все ответы парсятся как JSON

## Примеры использования

### Добавить товар в корзину
```javascript
addToCartQuick(1); // добавляет товар с ID 1
```

### Обновить счетчик в шапке
```javascript
updateCartBadge();
```

### Показать уведомление
```javascript
showNotification('Товар добавлен в корзину', 'success');
showNotification('Ошибка при добавлении', 'error');
```
