# Stationery Store - Интернет-магазин канцелярских товаров

ASP.NET MVC приложение - интернет-магазин канцелярских товаров с современным дизайном.

## Структура проекта

```
cursovaia2/
├── Controllers/
│   ├── HomeController.cs          # Главная страница, категории
│   ├── ProductController.cs       # Каталог товаров, фильтры, деталь товара
│   └── CartController.cs          # Управление корзиной
├── Models/
│   ├── Product.cs                 # Модель товара
│   ├── Cart.cs                    # Модель корзины
│   ├── CartItem.cs                # Элемент корзины
│   ├── Category.cs                # Категория товара
│   └── ErrorViewModel.cs
├── Services/
│   └── SessionExtensions.cs       # Расширения для работы с сессией
├── Views/
│   ├── Home/
│   │   ├── Index.cshtml           # Главная страница
│   │   ├── About.cshtml           # О магазине
│   │   └── Contacts.cshtml        # Контакты
│   ├── Product/
│   │   ├── Catalog.cshtml         # Каталог с фильтрами
│   │   └── Detail.cshtml          # Подробная информация о товаре
│   ├── Cart/
│   │   ├── Index.cshtml           # Корзина
│   │   ├── Checkout.cshtml        # Оформление заказа
│   │   └── OrderConfirmed.cshtml  # Подтверждение заказа
│   └── Shared/
│       └── _Layout.cshtml         # Главный layout
├── Program.cs                      # Конфигурация приложения
└── cursovaia2.csproj
```

## Функциональность

### Главная страница
- Баннер приветствия с градиентом
- Отображение категорий товаров
- Популярные товары

### Каталог товаров
- Список всех товаров с карточками
- Фильтрация по категориям
- Сортировка (по названию, цене возрастание/убывание)
- Красивые карточки товаров с описанием и ценой

### Подробная информация о товаре
- Изображение товара (заглушка)
- Полное описание
- Характеристики
- Быстрое добавление в корзину

### Корзина
- Просмотр добавленных товаров
- Изменение количества
- Удаление товаров
- Расчёт итоговой стоимости
- Оформление заказа

### Оформление заказа
- Форма с полями для доставки
- Итоговая информация о заказе
- Обработка заказа

### Дополнительно
- О магазине - информация и преимущества
- Контакты - способы связи и время работы

## Дизайн

### Цветовая схема
- Основной цвет: **#2563eb** (синий)
- Фоновый цвет: **#f8f9fa** (светло-серый)
- Белый фон для компонентов
- Градиент для баннеров: **#667eea → #764ba2**

### Стилевые элементы
- **Скругленные углы** (border-radius: 12px)
- **Мягкие тени** (box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1))
- **Hover-эффекты** с трансформацией (translateY)
- **Плавные переходы** (transition: all 0.3s ease)
- **Адаптивный дизайн** (Mobile-first подход)

### Компоненты
- Заголовок со стилизованным логотипом
- Навигационное меню
- Карточки товаров с hover-эффектом
- Кнопки разных стилей (primary, secondary, danger)
- Футер с секциями информации
- Таблица для отображения корзины
- Фильтры и сортировка

## Технологические особенности

### Без базы данных
- Все данные жёстко закодированы в контроллерах
- Готовая структура для подключения БД в будущем

### Управление состоянием
- Корзина хранится в **Session** (ISession)
- Сериализация объектов в JSON
- Расширения SessionExtensions для удобства

### MVC архитектура
- **Models**: Product, Cart, CartItem, Category
- **Controllers**: HomeController, ProductController, CartController
- **Views**: Razor Pages с встроенным CSS

### Функциональность
- Фильтрация товаров по категориям
- Сортировка товаров
- Управление корзиной (добавление, удаление, изменение количества)
- Оформление заказа

## Запуск проекта

```bash
# Восстановление зависимостей
dotnet restore

# Сборка проекта
dotnet build

# Запуск приложения
dotnet run
```

Приложение будет доступно по адресу `https://localhost:7001` или `http://localhost:5256`

## Возможности расширения

1. **Подключение БД**: Добавить Entity Framework Core с миграциями
2. **Авторизация**: Реализовать систему пользователей
3. **Платежи**: Интегрировать систему оплаты
4. **Email**: Отправка подтверждений заказов
5. **API**: Создать REST API для мобильных приложений
6. **Кэширование**: Добавить кэширование данных
7. **Поиск**: Полнотекстовый поиск товаров
8. **Отзывы**: Система рейтинга и отзывов
