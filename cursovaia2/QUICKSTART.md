# Быстрый старт - Stationery Store

## 📋 Предварительные требования

- **.NET 10.0** SDK или выше
- **Visual Studio 2022** (рекомендуется) или любой текстовый редактор
- **Git** (опционально)

## 🚀 Установка и запуск

### Способ 1: Через Visual Studio (рекомендуется)

1. **Открыть проект**
   - Запустить Visual Studio
   - `File` → `Open` → выбрать папку `cursovaia2`

2. **Восстановить пакеты**
   - Visual Studio автоматически восстановит пакеты
   - Или в Package Manager Console: `dotnet restore`

3. **Запустить проект**
   - Нажать `F5` или кнопку `Run`
   - Приложение откроется в браузере

### Способ 2: Через командную строку

```bash
# Перейти в папку проекта
cd cursovaia2

# Восстановить зависимости
dotnet restore

# Запустить проект
dotnet run

# Откроется: https://localhost:7001
```

### Способ 3: Публикация

```bash
# Создать релиз
dotnet publish -c Release -o ./publish

# Запустить опубликованное приложение
./publish/cursovaia2.exe
```

## 🌐 Использование приложения

### Главная страница
1. Откройте `https://localhost:7001` или `http://localhost:5256`
2. Вы увидите:
   - Баннер приветствия
   - Блок категорий (6 категорий)
   - Популярные товары (4 товара)

### Просмотр каталога
1. Нажмите **"Каталог"** в меню
2. Выберите категорию из выпадающего списка
3. Выберите способ сортировки
4. Нажмите **"Подробнее"** для информации о товаре

### Добавление в корзину
1. На странице товара нажмите **"🛒 В корзину"**
2. Товар добавится в корзину
3. Число в скобках рядом с "Корзина" увеличится

### Оформление заказа
1. Нажмите **"🛒 Корзина"** в меню
2. Измените количество товаров кнопками +/-
3. Нажмите **"Оформить заказ"**
4. Заполните форму с вашими данными
5. Нажмите **"💳 Оплатить заказ"**
6. Получите подтверждение заказа

### Другие страницы
- **О магазине** - Информация о компании и преимущества
- **Контакты** - Способы связи и социальные сети

## 🔧 Типичные задачи

### Добавить новый товар

1. Открыть `Controllers/ProductController.cs`
2. Найти метод `GetAllProducts()`
3. Добавить новый товар:
```csharp
new() { 
    Id = 25, 
    Name = "Новый товар", 
    Category = "Ручки", 
    Price = 50, 
    Description = "Описание", 
    ImageUrl = "/images/product.jpg", 
    Stock = 100 
}
```

### Изменить основной цвет

1. Открыть `Views/Shared/_Layout.cshtml`
2. Найти `--primary: #2563eb`
3. Изменить на нужный цвет

### Добавить новую категорию

1. Открыть `Controllers/HomeController.cs`
2. Найти метод `GetCategories()`
3. Добавить категорию:
```csharp
new() { Id = 7, Name = "Новая", Icon = "🎨" }
```

## 🐛 Решение проблем

### Ошибка: "Port 7001 already in use"

**Решение**:
```bash
# Изменить порт в launchSettings.json или
dotnet run --urls=https://localhost:7002
```

### Ошибка: "Session not working"

**Решение**: Убедитесь, что в `Program.cs` добавлено:
```csharp
builder.Services.AddSession();
app.UseSession();
```

### Ошибка: "View not found"

**Решение**: Проверить путь к файлу:
- `HomeController` action → `Views/Home/`
- `ProductController` action → `Views/Product/`
- `CartController` action → `Views/Cart/`

### Проект не собирается

**Решение**:
```bash
dotnet clean
dotnet restore
dotnet build
```
