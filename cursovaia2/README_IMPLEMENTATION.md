# Реализованные функции каталога и корзины

## Обзор

В проект добавлены полнофункциональные системы поиска, фильтрации, сортировки товаров и работающая корзина с AJAX операциями.

## Реализованные функции

### 1. **Динамический поиск товаров** ✅
- Поиск в реальном времени по названию и описанию товаров
- Дебаундинг (задержка 300мс) для оптимизации запросов
- HTML-экранирование для безопасности

### 2. **Фильтрация товаров** ✅
- Фильтр по категориям
- Фильтр по диапазону цен (от/до)
- Комбинированная фильтрация (работает одновременно)

### 3. **Сортировка товаров** ✅
- По названию (А-Я)
- По названию (Я-А)
- По цене (возрастание)
- По цене (убывание)

### 4. **Интерактивная корзина** ✅
- Добавление товаров в корзину с AJAX (без перезагрузки страницы)
- Удаление товаров из корзины с AJAX
- Изменение количества товаров в корзине с AJAX
- Очистка корзины
- Обновление счетчика товаров в шапке сайта в реальном времени

### 5. **Уведомления пользователю** ✅
- Всплывающие уведомления при добавлении/удалении товаров
- Анимированные уведомления об успехе или ошибке
- Автоматическое исчезновение через 3 секунды

### 6. **Отзывчивый дизайн** ✅
- Адаптивная сетка товаров
- Мобильная оптимизация
- Удобные размеры кнопок и элементов управления

## Структура кода

### Controllers

#### ProductController.cs
- `Catalog()` - Загружает каталог
- `GetFilteredProducts()` - API endpoint для получения отфильтрованных товаров с сортировкой

#### CartController.cs
- `AddToCartAjax()` - AJAX добавление товара в корзину
- `RemoveItemAjax()` - AJAX удаление товара из корзины
- `UpdateQuantityAjax()` - AJAX обновление количества товара
- `GetCartData()` - API endpoint для получения данных корзины

### Views

#### Views/Product/Catalog.cshtml
- Фильтры (поиск, категория, цена, сортировка)
- Кнопка "Очистить фильтры"
- Динамический список товаров
- JavaScript логика для фильтрации и сортировки

#### Views/Cart/Index.cshtml
- Таблица с товарами в корзине
- AJAX кнопки для удаления товаров
- AJAX элементы управления количеством
- Автоматическое обновление итогов

#### Views/Shared/_Layout.cshtml
- Счетчик товаров в корзине в шапке (обновляется в реальном времени)

## Тестовые товары

Проект включает 24 тестовых товара в 6 категориях:
- **Ручки** (4 товара) - от 25 до 45 руб.
- **Карандаши** (4 товара) - от 15 до 120 руб.
- **Тетради** (4 товара) - от 25 до 65 руб.
- **Блокноты** (4 товара) - от 55 до 95 руб.
- **Клей и скотч** (4 товара) - от 20 до 40 руб.
- **Папки и файлы** (4 товара) - от 45 до 85 руб.

## API Endpoints

### POST /Product/GetFilteredProducts
Параметры:
- `search` - текст поиска (опционально)
- `category` - название категории (опционально)
- `sort` - тип сортировки: name, name-desc, price-asc, price-desc
- `priceMin` - минимальная цена (опционально)
- `priceMax` - максимальная цена (опционально)

Ответ:
```json
{
  "success": true,
  "products": [...]
}
```

### POST /Cart/AddToCartAjax
Параметры:
- `productId` - ID товара
- `quantity` - количество (опционально, по умолчанию 1)

Ответ:
```json
{
  "success": true,
  "message": "Товар добавлен в корзину",
  "itemCount": 1,
  "total": 25
}
```

### POST /Cart/RemoveItemAjax
Параметры:
- `cartItemId` - ID товара в корзине

Ответ:
```json
{
  "success": true,
  "message": "Товар удален из корзины",
  "itemCount": 0,
  "total": 0
}
```

### POST /Cart/UpdateQuantityAjax
Параметры:
- `cartItemId` - ID товара в корзине
- `quantity` - новое количество

Ответ:
```json
{
  "success": true,
  "message": "Количество обновлено",
  "itemCount": 2,
  "total": 50
}
```

### GET /Cart/GetCartData
Ответ:
```json
{
  "itemCount": 2,
  "total": 50,
  "items": [...]
}
```

## Технологии

- **Frontend**: Vanilla JavaScript (без зависимостей)
- **Backend**: ASP.NET Core 10, C#
- **Стилизация**: CSS Grid, Flexbox
- **Хранение сессии**: ASP.NET Core Session (HttpContext)

## Инструкции по использованию

1. Откройте каталог товаров: `/Product/Catalog`
2. Используйте фильтры для поиска нужного товара:
   - Введите текст в поле поиска
   - Выберите категорию из выпадающего списка
   - Установите диапазон цен
   - Выберите способ сортировки
3. Нажмите "🛒 В корзину" для добавления товара (без перезагрузки страницы)
4. Перейдите в корзину: `/Cart/Index`
5. Измените количество товаров или удалите ненужные товары
6. Оформите заказ через кнопку "Оформить заказ"

## Примечания

- Все данные товаров хранятся в памяти (В будущем подключить БД)
- Корзина хранится в сессии браузера
- При перезагрузке страницы фильтры сбрасываются (данные товаров остаются)
- Все операции с корзиной работают без перезагрузки страницы благодаря AJAX
