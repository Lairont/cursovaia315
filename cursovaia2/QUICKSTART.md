# 🎉 Stationery Store - Готово к использованию!

## 📌 Что было реализовано

✅ **Полный функционал интернет-магазина:**

### 1️⃣ Аутентификация и управление пользователями
- Регистрация новых пользователей
- Логин/Логаут
- Хранение паролей с хешированием (SHA256)
- Сохранение сеанса

### 2️⃣ Каталог товаров
- Просмотр всех товаров
- Фильтрация по категориям
- Подробная информация о товаре
- Характеристики и изображения товаров

### 3️⃣ Система корзины
- Для анонимных: хранение в сессии
- Для авторизованных: хранение в БД
- Добавление/удаление товаров
- Очистка корзины
- Обновление количества товаров

### 4️⃣ Оформление заказов
- Ввод адреса доставки
- Выбор способа доставки
- Выбор способа оплаты
- Сохранение заказа в БД

### 5️⃣ История заказов
- Просмотр всех заказов пользователя
- Информация о статусе заказа
- Список товаров в заказе
- Общая сумма

### 6️⃣ База данных
- PostgreSQL с 18 таблицами
- EF Core миграции
- Полные связи между таблицами
- Тестовые данные

---

## 🚀 Как начать использовать

### Шаг 1: Запустите приложение
```bash
dotnet run
```

### Шаг 2: Откройте в браузере
```
http://localhost:5000
```

### Шаг 3: Добавьте тестовые данные
Перейдите по ссылке:
```
http://localhost:5000/Test/AddTestData
```

Это добавит:
- 5 товаров
- 1 категорию
- 1 бренд
- Тестового пользователя

### Шаг 4: Используйте приложение

**Два способа начать:**

**Вариант A: Как анонимный пользователь**
1. Перейдите в `/Product/Catalog`
2. Добавьте товары в корзину (сохранится в сессии)
3. Просмотрите корзину в `/Cart/Index`

**Вариант B: Как авторизованный пользователь**
1. Зарегистрируйтесь: `/Account/Register`
   - Email: ваш_email@example.com
   - Пароль: ваш_пароль
2. Логинитесь: `/Account/Login`
3. Добавляйте товары в корзину (сохранится в БД)
4. Оформляйте заказы: `/Checkout/Index`
5. Смотрите историю заказов: `/Checkout/Orders`

## 💾 Структура БД

**Основные таблицы:**
- `users` - Пользователи
- `customers` - Покупатели
- `products` - Товары
- `categories` - Категории
- `brands` - Бренды
- `carts` - Корзины (для авторизованных)
- `cart_items` - Элементы корзины
- `orders` - Заказы
- `order_items` - Элементы заказов
- `roles` - Роли
- И другие вспомогательные таблицы
