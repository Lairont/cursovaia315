# Инструкция по тестированию

## 1. Запуск приложения

```
cd D:\работы\cursovaia2
dotnet run
```

Приложение будет доступно по адресу: `https://localhost:5001` или `http://localhost:5000`

## 2. Тестирование поиска

### Тест 2.1: Поиск по названию
1. Перейти в `/Product/Catalog`
2. В поле "Поиск" введите "ручка"
3. ✅ Должны отобразиться товары с "ручка" в названии (Шариковая ручка Blue, Шариковая ручка Red, Гелевая ручка, Ручка-маркер)

### Тест 2.2: Поиск по описанию
1. В поле "Поиск" введите "премиум"
2. ✅ Должны отобразиться товары с "премиум" в описании (Гелевая ручка, Блокнот Premium)

### Тест 2.3: Поиск не дает результатов
1. В поле "Поиск" введите "несуществующий"
2. ✅ Должна появиться фраза "Товары не найдены"

## 3. Тестирование фильтрации

### Тест 3.1: Фильтр по категориям
1. Перейти в `/Product/Catalog`
2. Выберите категорию "Ручки"
3. ✅ Должны отобразиться только товары категории "Ручки" (4 товара)
4. Выберите "Все категории"
5. ✅ Должны отобразиться все товары (24)

### Тест 3.2: Фильтр по цене
1. В поле "Цена от" введите "40"
2. ✅ Должны остаться только товары дороже 40 руб.
3. В поле "до" введите "100"
4. ✅ Должны остаться только товары между 40 и 100 руб.

### Тест 3.3: Комбинированная фильтрация
1. Выберите категорию "Тетради"
2. Введите в "Цена от": "30"
3. Введите в "до": "70"
4. ✅ Должны остаться только тетради между 30-70 руб. (2 товара)

## 4. Тестирование сортировки

### Тест 4.1: Сортировка по названию (А-Я)
1. Выберите "По названию (А-Я)"
2. ✅ Первый товар должен начинаться на "Б" или ранее, последний на "Щ" или позже

### Тест 4.2: Сортировка по названию (Я-А)
1. Выберите "По названию (Я-А)"
2. ✅ Первый товар должен начинаться на "Щ" или позже, последний на "Б" или ранее

### Тест 4.3: Сортировка по цене возрастание
1. Выберите "Дешевле"
2. ✅ Цены должны расти слева направо (20 < 25 < 45 и т.д.)

### Тест 4.4: Сортировка по цене убывание
1. Выберите "Дороже"
2. ✅ Цены должны падать слева направо (120 > 95 > 85 и т.д.)

## 5. Тестирование корзины

### Тест 5.1: Добавление товара в корзину
1. На странице каталога нажмите "🛒 В корзину" на любом товаре
2. ✅ Должно появиться зелёное уведомление "✓ Товар добавлен в корзину"
3. ✅ Счетчик в шапке должен обновиться с "0" на "1"
4. Страница не должна перезагружаться

### Тест 5.2: Добавление нескольких товаров
1. Добавьте 3 разных товара в корзину
2. ✅ Счетчик в шапке должен показать "3"
3. ✅ Каждое добавление должно показать уведомление

### Тест 5.3: Добавление одинакового товара
1. Добавьте один товар в корзину
2. Добавьте тот же товар ещё раз
3. ✅ В корзине должен остаться 1 товар с количеством "2"

### Тест 5.4: Открытие корзины
1. Нажмите на "🛒 Корзина" в шапке
2. ✅ Должны отобразиться все добавленные товары

### Тест 5.5: Изменение количества товара
1. На странице корзины в строке товара нажмите "+"
2. ✅ Количество должно увеличиться на 1
3. ✅ Итоговая сумма должна обновиться
4. ✅ Счетчик в шапке должен увеличиться

### Тест 5.6: Удаление товара из корзины
1. На странице корзины нажмите "🗑️" рядом с товаром
2. ✅ Должно появиться диалоговое окно "Вы уверены?"
3. Нажмите ОК
4. ✅ Товар должен исчезнуть из таблицы
5. ✅ Счетчик в шапке должен обновиться
6. ✅ Появится зелёное уведомление

### Тест 5.7: Очистка корзины
1. На странице корзины нажмите "🗑️ Очистить корзину"
2. ✅ Должно появиться подтверждение "Очистить корзину?"
3. Нажмите ОК
4. ✅ Таблица товаров должна исчезнуть
5. ✅ Должна появиться фраза "Корзина пуста"
6. ✅ Счетчик в шапке должен обнулиться

## 6. Тестирование очистки фильтров

### Тест 6.1: Кнопка "Очистить"
1. Установите фильтры: категория "Ручки", цена от 30 до 50
2. Нажмите "Очистить"
3. ✅ Все фильтры должны сброситься
4. ✅ Должны отобразиться все 24 товара

## 7. Тестирование на мобильных устройствах

### Тест 7.1: Адаптивность каталога
1. Откройте `/Product/Catalog` на мобильном устройстве
2. ✅ Фильтры должны быть расположены в колонку
3. ✅ Товары должны отображаться в 1-2 колонках

### Тест 7.2: Адаптивность корзины
1. Откройте `/Cart/Index` на мобильном устройстве
2. ✅ Таблица должна быть читаемой и адаптированной

## 8. Тестирование производительности

### Тест 8.1: Быстрая фильтрация
1. Введите в поиск "ручка" (медленно, по одной букве)
2. ✅ Не должно быть задержек более 300мс между вводом и обновлением
3. ✅ Запросы не должны дублироваться при быстром вводе

## 9. Проверка безопасности

### Тест 9.1: HTML-экранирование
1. В поле поиска введите: `<img src=x onerror=alert('XSS')>`
2. ✅ Должны появиться результаты, но скрипт не должен выполниться

## 10. Тестирование граничных случаев

### Тест 10.1: Пустые фильтры
1. Оставьте все фильтры пустыми
2. ✅ Должны отобразиться все 24 товара

### Тест 10.2: Противоречивые фильтры
1. Установите цену от 100 до 20 (от большей к меньшей)
2. ✅ Не должно быть ошибок, должна отобразиться пустая корзина

### Тест 10.3: Обновление страницы в корзине
1. Добавьте товары в корзину
2. Обновите страницу (F5)
3. ✅ Товары должны остаться в корзине
4. ✅ Счетчик должен остаться актуальным

## Результаты тестирования

После прохождения всех тестов система должна:
- ✅ Выполнять поиск без перезагрузки страницы
- ✅ Фильтровать товары по всем параметрам
- ✅ Сортировать товары корректно
- ✅ Добавлять/удалять товары в корзину без перезагрузки
- ✅ Обновлять счетчик в реальном времени
- ✅ Сохранять корзину при перезагрузке
- ✅ Работать на мобильных устройствах
- ✅ Быть защищённой от XSS атак
