# 🚀 ПЕРВЫЕ ШАГИ - Как начать работу с приложением

## ⚡ Быстрый старт (3 минуты)

### 1️⃣ Запустить приложение
```bash
dotnet run
```

**Вывод:**
```
Starting Stationery Store...
info: Application started at http://localhost:5000
```

### 2️⃣ Открыть в браузере
```
http://localhost:5000
```

Вы увидите красивую главную страницу с кнопками.

### 3️⃣ Добавить тестовые данные
Нажмите кнопку **"📊 Добавить тестовые данные"** на главной странице

**ИЛИ** откройте в браузере:
```
http://localhost:5000/Test/AddTestData
```

**Результат:**
- ✅ Добавлены 5 товаров
- ✅ Добавлена категория
- ✅ Добавлен бренд
- ✅ Готово к использованию!

## 🛍️ Сценарий использования #1: Анонимный покупатель

### Шаг 1: Перейти в каталог
```
http://localhost:5000/Product/Catalog
```

### Шаг 2: Выбрать товар и добавить в корзину
- Нажмите на любую карточку товара
- Нажмите **"Добавить в корзину"**
- Увидите уведомление ✅

### Шаг 3: Просмотреть корзину
```
http://localhost:5000/Cart/Index
```

**Вы увидите:**
- Таблицу товаров
- Количество каждого товара
- Итоговую стоимость
- Кнопку **"Оформить заказ"**

### Шаг 4: Оформить заказ
- Нажмите **"Оформить заказ"**
- Вам предложат **залогиниться**
- Зарегистрируйтесь или используйте тестового пользователя

## 👤 Сценарий использования #2: Авторизованный пользователь

### Вариант A: Регистрация новой учётной записи

#### Шаг 1: Перейти на страницу регистрации
```
http://localhost:5000/Account/Register
```

#### Шаг 2: Заполнить форму
```
Email: myemail@example.com
Password: MyPassword123
```

#### Шаг 3: Нажать кнопку "Зарегистрироваться"
- Вы будете перенаправлены на главную
- Теперь вы авторизованы! ✅

### Вариант B: Логин с тестовым пользователем

#### Шаг 1: Перейти на страницу логина
```
http://localhost:5000/Account/Login
```

#### Шаг 2: Ввести данные
```
Email: test@example.com
Password: (используйте свой пароль при регистрации)
```

#### Шаг 3: Нажать "Войти"
- Вы авторизованы! ✅

## 🛒 Полный процесс покупки

### 1. Просмотр каталога
```
/Product/Catalog
```
- Видите все товары
- Можете фильтровать по категориям

### 2. Просмотр детали товара
- Нажмите на товар
- Увидите:
  - Полное описание
  - Характеристики
  - Цену
  - Кнопку "Добавить в корзину"

### 3. Добавление в корзину
- Выберите количество
- Нажмите "Добавить в корзину"
- Увидите уведомление
- Счётчик корзины обновится автоматически

### 4. Просмотр корзины
```
/Cart/Index
```
**Видите:**
- Все товары в корзине
- Кнопку удаления для каждого товара
- Кнопку "Очистить корзину"
- Итоговую стоимость
- Кнопку "Оформить заказ"

### 5. Оформление заказа
```
/Checkout/Index
```
**Заполнить:**
- Адрес доставки
- Выбрать способ доставки:
  - 🚚 Стандартная (300₽, 5-7 дней)
  - ⚡ Экспресс (800₽, 1-2 дня)
  - 🏪 Самовывоз (бесплатно)
- Выбрать способ оплаты

**Нажать:**
- Кнопку "Оформить заказ"

### 6. Подтверждение заказа
**Видите:**
- Номер заказа
- Дату оформления
- Итоговую сумму
- Список товаров
- Ссылку на историю заказов

### 7. История заказов
```
/Checkout/Orders
```
**Видите:**
- Все свои заказы
- Дату каждого заказа
- Количество товаров
- Итоговую сумму

## 💾 Где хранятся данные?

### Корзина:
- **Для анонимных**: В сессии на сервере (сессия = 20 минут неактивности)
- **Для авторизованных**: В БД (таблица `carts`)

### Заказы:
- В БД (таблица `orders`)

### Пользователи:
- В БД (таблица `users`)

### Товары:
- В БД (таблица `products`)

## ❓ Частые вопросы

### Q: Где логин/пароль?
**A:** Вверху справа, кнопка "Вход" → можете выбрать регистрацию или логин

### Q: Как добавить товар в корзину?
**A:** На любой карточке товара нажмите "Добавить в корзину" или перейдите на детальную страницу и нажмите там

### Q: Где мои заказы?
**A:** Перейдите в "Мои заказы" → `/Checkout/Orders` (только для авторизованных)

### Q: Как очистить корзину?
**A:** Перейдите в корзину `/Cart/Index` и нажмите "Очистить корзину"

### Q: Где удалить товар из корзины?
**A:** В корзине есть кнопка "Удалить" для каждого товара

### Q: Как выйти из аккаунта?
**A:** Нажмите на свой email в верхней правой части и выберите "Выход"
