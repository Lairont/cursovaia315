# 🛍️ Stationery Store - Интернет магазин канцелярских товаров

## 📋 Описание

Полнофункциональный интернет-магазин канцелярских товаров, построенный на ASP.NET Core с использованием Razor Pages и Entity Framework Core.

## ✨ Функции

### ✅ Готовые функции:
- **Аутентификация**: Регистрация и логин пользователей
- **Каталог товаров**: Просмотр товаров по категориям
- **Карточки товаров**: Подробная информация о каждом товаре
- **Корзина**: 
  - Для анонимных пользователей (хранится в сессии)
  - Для авторизованных пользователей (хранится в БД)
- **Оформление заказов**: Полный процесс оформления
- **История заказов**: Просмотр своих заказов
- **Управление учетной записью**: Профиль пользователя

## 🚀 Начало работы

Откройте браузер и перейдите по адресам:

```
http://localhost:5000/Test/AddTestData
```

Это добавит тестовые данные в БД:
- 5 товаров в каталоге
- 1 тестовую категорию
- 1 тестовый бренд
- Тестового пользователя (test@example.com)

### 2. Проверка БД

```
http://localhost:5000/Test/CheckDatabase
```

Просмотрит статистику БД и количество записей в каждой таблице.

## 🗄️ База данных

### Таблицы:
- `users` - Пользователи
- `customers` - Покупатели
- `roles` - Роли
- `categories` - Категории товаров
- `brands` - Бренды
- `products` - Товары
- `product_images` - Изображения товаров
- `product_attributes` - Характеристики товаров
- `carts` - Корзины (для авторизованных)
- `cart_items` - Элементы корзины
- `orders` - Заказы
- `order_items` - Элементы заказов
- `payments` - Платежи
- `deliveries` - Доставки
- `discounts` - Скидки
- `promo_codes` - Промокоды

## 🛒 Процесс покупки

1. **Просмотр каталога**: Перейдите в /Product/Catalog
2. **Выбор товара**: Нажмите на товар или кнопку "Добавить в корзину"
3. **Просмотр корзины**: /Cart/Index
4. **Оформление заказа**: /Checkout/Index (требует авторизации)
5. **Подтверждение**: Заказ добавляется в БД
6. **История заказов**: /Checkout/Orders
