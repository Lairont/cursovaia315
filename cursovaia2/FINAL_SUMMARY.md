## 🎯 Сценарии использования

### Анонимный пользователь:
```
1. Просмотреть каталог
2. Добавить товары в корзину
3. Просмотреть корзину
4. Зарегистрироваться / Залогиниться
5. Оформить заказ
```

### Авторизованный пользователь:
```
1. Залогиниться
2. Просмотреть каталог
3. Добавить товары в корзину (сохранится в БД)
4. Оформить заказ
5. Просмотреть историю заказов
```
