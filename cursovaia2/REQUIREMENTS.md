## 🎨 UI/UX Особенности

### Цвета
- Primary: #2563eb (Синий)
- Secondary: #e2e8f0 (Серый)
- Danger: #ef4444 (Красный)
- Gradient: #667eea → #764ba2

### Typography
- Заголовки: Bold, крупные (1.5-2.5rem)
- Текст: Regular, средние (0.95-1.1rem)
- Labels: Semi-bold, маленькие (0.85-0.9rem)

### Spacing
- Small: 0.5rem
- Medium: 1rem
- Large: 2rem
- Extra Large: 3rem

### Shadows
- Light: 0 2px 8px rgba(0, 0, 0, 0.1)
- Medium: 0 8px 16px rgba(0, 0, 0, 0.15)

### Border Radius
- Buttons: 8px
- Cards: 12px
- Inputs: 6px

## 📱 Адаптивность

- **Desktop**: Полная версия (> 768px)
- **Tablet**: Оптимизированная версия (768px)
- **Mobile**: Мобильная версия (< 768px)

### Адаптивные компоненты
- Grid переходит на 1 колонку на мобильных
- Flex layout обеспечивает текучесть
- Font sizes масштабируются
- Padding/margin адаптивные
